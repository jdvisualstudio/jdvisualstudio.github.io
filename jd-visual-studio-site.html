Le studio

Un regard qui vient du terrain

JD Visual Studio est né sur le terrain, caméra à l'épaule, avant de devenir un studio de création complet.

Fondé par Jean David Nessonon, le studio est parti des premiers tournages en équipe — mariages, concerts, événements — pour construire progressivement une véritable vision éditoriale : cadrer, monter, raconter, mettre en page. Chaque nouvel outil, jusqu'à l'intelligence artificielle aujourd'hui, sert une seule idée : donner plus de moyens à un savoir-faire déjà là.

Le studio travaille avec des entreprises locales qui veulent un support de communication qui leur ressemble vraiment, pas un modèle générique de plus.

Jean David Nessonon Fondateur, JD Visual Studio
